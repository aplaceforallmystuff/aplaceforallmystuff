## csAIi: from tools to a working system

[csAIi](https://csaii.jimchristian.net) is my framework for how people and AI work together:

**Context → Skills → Agents → Integration → Iteration**

The order matters. Start with what the system needs to know, build repeatable skills, give agents bounded roles, connect the parts, then improve from evidence.

Two open-source methods sit beneath csAIi:

- **[PAST](https://github.com/aplaceforallmystuff/past-framework)** — Purpose, Audience, Scope, Tone: clarify what an AI initiative is for.
- **[SHAPE](https://github.com/aplaceforallmystuff/shape-framework)** — Situation, Hypothesis, Action, Process, Evaluation: move from intent to disciplined execution.

Different domains, same job: making separate technologies work together in ways people can use.
